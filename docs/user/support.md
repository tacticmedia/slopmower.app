## Contact us

Send an email to [TO SUPPLY: support email]. Include:

- your GitHub login;
- the repository and the review, for example the URL of the page in Slopmower;
- what you did, what you expected, and what happened;
- the error message or the error code, for example `limit_exceeded`.

Do not send code, API tokens, or other secrets. We never ask for a token.

## Plans and billing

The GitHub Marketplace bills the paid plans. To change or cancel a plan, use the Slopmower listing on the GitHub Marketplace or the billing settings of your GitHub account. For a question about a payment, contact GitHub Support. For a question about the limits of a plan, contact us.

## Your data

- To delete your account and all its data, click **Delete account** in **Settings**.
- For a privacy request, write to [TO SUPPLY: privacy email]. The [privacy policy](privacy.md) lists your rights.

## Report a security problem

Send the details to [TO SUPPLY: support email], with "Security" in the subject. Do not publish the details before we answer.
