# Keyboard shortcuts

On macOS, press Cmd where the table says Ctrl. Outside macOS, press Ctrl.

| Keys | Where | What it does |
|---|---|---|
| Ctrl+K | A review | Opens or closes **Quick open**. It does nothing while you type in a text field. |
| Up and Down arrows, then Enter | **Quick open** | Opens the chosen file or symbol |
| Escape | **Quick open** | Closes the dialog |
| Ctrl+Enter | A comment box | Sends the comment with its submit button, for example **Add single comment** or **Reply** |
| Escape | A comment box with **Cancel** | Cancels the comment |
| Enter | The **Title** field of a comment box | Moves to the **Description** |
| Enter or Space | The **+** on the last selected line | Opens the comment box below the selected lines |
| Shift-click | A line number | Selects the lines from the line number that you clicked before |
| Up and Down arrows, then Enter | **Symbols** | Comments on the chosen symbol |
| Ctrl-click | A name in a PHP file | Opens its declaration |
| Enter | **Go to declaration** | Opens the declaration of the typed name |
| Arrow keys | The focused edge of the file tree | Changes the width of the tree |
| Enter | The title of a request, while you edit it | Saves the title |
| Escape | The title of a request, while you edit it | Keeps the old title |
| Escape | The review tour | Ends the current part of the tour |

The other controls work with Tab, Enter, and Space, like the controls of every web page. [Comment on code](comment.md#with-the-keyboard) shows how to comment with the keyboard only.
