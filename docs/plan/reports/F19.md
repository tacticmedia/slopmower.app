- **Summary:**
  - The user command `set_plan_requirement`, REST Q18 `POST /api/v1/requests/{requestId}/plan-requirement` (session only) with `PlanRequirementInput {requireApproval}`, answers `RequestCommandResult`. It is allowed for the user on an `open`, `reopened`, or `in_progress` request of an open review. No MCP tool.
