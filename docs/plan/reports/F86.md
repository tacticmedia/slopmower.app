- **Summary:**
  - 7, D91: `RepositoryLock::withPinLock()` takes the `pins:<repositoryId>` advisory lock around the pin and the transaction of `link_commits`, and around the link check and the unpin of `unlink_commit` and of a review deletion.
  - 8, D92: the asynchronous fetch job runs `git -c gc.autoDetach=false gc --auto --quiet` after the fetch and before the size measurement, within the rest of the job timeout. A gc failure is logged.

  - 14: `mcp_http` is keyed by the user.
  - 15, D95: an hourly scheduled `QueueStalledIndexesJob` queues `IndexReview` for each open review whose index is `pending` 1 hour after its start. `start()` logs a failed dispatch and returns the review.
  - 16: `readmeUrl.ts` keeps a segment with a malformed escape as it is.
  - 17: `tree-entries` never revalidates, and `CodeLayout` only when `reviewId` changes.
  - 18: `GitReader::pathAfter()` keeps the changed paths per git directory and commit range until `reset()`.
  - 19: `ThreadQuery::entriesOfRequests()` reads the threads of all requests of a `get_updates` page in one query. `entries()` uses it.
  - 20: `symfony/intl` and the direct `symfony/form` requirement are gone, and `helgesverre/toon` is in `require-dev`. Only these packages changed in `composer.lock`.
