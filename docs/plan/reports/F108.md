## Report: F108 Structured agent questions

- **Status:** Done 2026-11-03.
- **Summary:**
  - `request.commented` has `questions: list<{question, detail, answer}>`, read as `[]` when missing. Every event and thread entry carries `questions`, `[]` when it is not a comment (D107).
  - Q4 and `reply_to_request` take up to 10 questions. An agent comment with questions is stored with `question: true`, so the request waits for the user. A user comment with questions answers them: every item has an answer, and the body can be empty.
  - The web UI shows the open questions above the reply box, after the next-step line: each question with its Markdown detail, "Yes", "No", and an "Other answer" field, then "Send answers", which is enabled when every question has an answer. It sends Q4 with an empty body and each question with its answer. The open questions are those of the latest agent comment with questions, until a later user comment has questions.
  - Questions that are not open render under the body of their comment: an agent's with their detail, a user's with their answers. A user comment with answers and no text has no body.
  - The next-step line says "The agent asked questions. Answer them to continue." while the open question has questions.
  - The skill and the server instructions tell the agent to ask with `questions` and to read the answers from the user comment.
