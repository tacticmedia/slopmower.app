## Report: F85 Audit fixes 4 to 6

- **Status:** Done 2026-10-29, `14569a5`.
- **Summary:**
  - `LiveSubscription::catchUp()` returns after a failed read of the missed events and revalidates nothing, so the route error no longer replaces the page and an unsent comment. The next open, visibility change, or live update catches up.
  - D90: `ServerClone::pendingShas()` passes only the pending links of the last 7 days to the fetch. `BareClone::fetch()` sets `HEAD` before the pending SHAs, and the pending step stops at the timeout without failing the fetch. An older pending link stays `pending` and resolves when a branch or a tag brings its commit.
  - NUL bytes: `ApiNulByteListener` refuses U+0000 in any query value or JSON body string under `/api/v1` with 422 `invalid_input` and the dotted field. Every MCP string parameter without another pattern has `NO_NUL` (`^[^\x00]*$`), and `PULL_REQUEST_URL` excludes NUL, so the SDK answers -32602. `common.schema.json` has the definition `NoNulText`, and its `PullRequestUrl` pattern excludes NUL.
