- **Risks discovered:**
  - PHPStan reads `var/cache/dev/App_KernelDevDebugContainer.xml` without a freshness check. Build the dev container first. `make stan` does this with `cache:warmup --env=dev`. A shell with `APP_ENV=test` and only `cache:clear` would leave the XML stale.
  - PHPStan parses for the PHP version of the runtime, not for `require.php`. On a PHP 8.4 runtime, PHP 8.5 syntax such as the pipe operator fails to parse. The container uses 8.5.
  - Panther 2.4 with PHPUnit 13 is checked only statically: the extension class implements the PHPUnit 10+ interface, and Panther declares no PHPUnit conflict. M01's `BrowserSmokeTest` is the runtime proof.
  - Every Composer run on PHP 8.5 prints a deprecation notice from `symfony/flex` 2.11.0, the latest version (`Flex.php:183`, null array offset). It has no effect.
