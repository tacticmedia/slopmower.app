## Report: F122 Shannon pentest of a disposable HTTPS stack

- **Status:** Done.
- **Summary:**
  - `make pentest` runs `bin/pentest`. It clones HEAD into `var/pentest/repositories/`, starts the compose project `slopmower-pentest` (`compose.yaml` plus `compose.pentest.yaml`) with HTTPS on 8343 and its own database and `var/`, loads the dev fixtures as `pentest`, and runs `npx @keygraph/shannon@3.5.0 start --follow`. On exit it stops its own scan and removes the stack with its volumes.
  - Caddy serves `host.docker.internal` with a certificate of its local CA. `docker/shannon/Dockerfile` derives the Shannon worker, pinned by digest, and accepts that certificate in the browser (`PLAYWRIGHT_MCP_IGNORE_HTTPS_ERRORS`) and in curl (`.curlrc` with `insecure`). `bin/pentest` builds it as `keygraph/shannon:3.5.0`, the local tag that the CLI runs.
  - `shannon.yaml` holds the target description, the scope rules, the one-click sign-in, the dev-only routes to avoid, and the report guidance.
  - On exit, `bin/pentest` saves the logs of `php` and `worker` to `target.log` in the report directory, so a later reader can see whether the scan met server errors.

- **Decisions and deviations:**
  - `bin/pentest` builds the Shannon tag as its last step before `shannon start`, not as its first step. The cisomat.com project on this host builds its own `keygraph/shannon:3.5.0` (with its CA only) before each of its scans. The two projects agreed that each one builds the tag directly before its own start, and that the two starts never run at the same time.
  - The Shannon CLI runs its own compose project for Temporal. `bin/pentest` runs the CLI without `COMPOSE_PROJECT_NAME`, `COMPOSE_FILE`, and `COMPOSE_PROFILES`, so a shell value cannot rename that project. The cisomat.com session found this.
  - `bin/pentest` stops when `public/entrypoints.json` points to the Vite dev server, which the Shannon worker cannot reach.
  - `compose.pentest.yaml` also sets `MERCURE_PUBLIC_URL` to `https://host.docker.internal:8343/.well-known/mercure`. The first full run showed that the value of `.env.dev` (`http://localhost:8300/...`) makes every `POST /api/v1/mercure/authorize` fail with 500: Symfony Mercure refuses an authorization cookie for a hub on another domain.
  - `shannon.yaml` has no `code_path` rule for `.claude/`, which the scope file planned. Shannon turns `.claude/**` into the deny patterns `.claude/*` and `*/.claude/*` (`apps/worker/src/ai/pi/permission-system.ts`). The second pattern also blocks `/tmp/.claude/skills/playwright-cli/SKILL.md`, the browser guide that Shannon gives its own agents. In the first full run, the recon agent failed to read that file 4 times.
  - After the second run, `rules_of_engagement` also says that the local sign-in is a dev-only stand-in for GitHub sign-in, to use for signing in and not to test. `report.guidance` drops such findings only when the report is written, so in the second run the analysis and exploitation agents still spent time on it, and the refusal happened on it. An `avoid` rule for `/login/local` cannot do this, because Shannon signs in through it.
  - `bin/pentest` saves the target logs in the report directory before it removes the stack. The scim session suggested this.
  - The first full run was stopped after 32 min, in recon, to apply these two fixes. Shannon reported $5.82 (pre-recon only; a cancelled agent is not in the total). The browser logs of that run showed 53 responses with 200 from the target and no certificate error.

- **Risks discovered:**
  - Every Shannon 3.5.0 scan on this host runs the derived image that was built last, by this project or by cisomat.com. A started worker keeps its image.
  - Shannon v3 needs an API key (`~/.shannon/config.toml`, model `claude-sonnet-5`). It does not use a Claude Code subscription. Every Shannon scan on this host that sets no key in its environment uses the same key.
  - Anthropic's cyber safeguard can refuse a turn in the middle of a run and fail an agent without a retry, even after the preflight check passed. The report then lists the class as not assessed.
  - A full run costs about $34, and a stopped run still costs what its agents spent.
