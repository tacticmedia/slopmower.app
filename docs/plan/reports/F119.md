## Report: F119 Comment form fixes

- **Status:** Done 2026-11-05.
- **Summary:**
  - A drag selection of lines scrolls the window near the top or the bottom edge while more code lies beyond it. `CodeFile` starts a frame loop at the start of the gesture and stops it at the release. After each scroll step it sends the view a `pointermove` at the pointer, kept inside the code, because `@pierre/diffs` extends a selection only on `pointermove`. The same loop serves a drag from the gutter "+".
  - The edit of a pending comment highlights its lines through the new `highlight` prop of `CodeFile`, which is never scrolled to and leaves the URL hash alone.
  - The title and description fields show the placeholders "Title (optional)" and "Description". Their labels are visually hidden, so the accessible names stay. The request options are on their own row above the buttons.
  - In the file view, the edit of a pending comment on lines shows "Lines X to Y" with **Update selection**, which turns the numbers into inputs; **Done** or Enter applies them, and Escape drops them. **Update comment** sends the new anchor through D3 (D115).

  - Back end: `src/Controller/Api/DraftController.php`, `src/Controller/Api/Input/UpdateDraftInput.php`, `src/Entity/Draft.php`.

- **Verification:**
  - Mutation: with the drag loop switched off in `CodeFile`, the `DragSelection` test fails on the scroll position. Restored after the run.
  - Screenshots of the edit, the inputs, the error, and a new comment box, taken through the mocked API, checked by eye.
  - `make check`: see the status row.
- **Decisions and deviations:**
  - The range edit applies inputs that are still open when **Update comment** is clicked, so typed numbers are never dropped silently.
  - The read text and the inputs share one grid cell, so the cell is as wide as the inputs. In read mode this leaves a gap of about 30 px before **Update selection** on a file with two-digit line numbers.
  - The context `DraftLinesContext` wraps only the code view: drafts on the file have no lines.
  - Not done: the manual run on the worktree stack in Chrome. The UI tests run in Chromium against the mocked API.
