# Report: M03 Domain events and payload codec

- **Status:** Done, on `main`, 2026-09-29.
- **Summary:** 14 event classes in `src/Domain/Event`, one per `EventType`, each with `toPayload()` and `fromPayload()`. `RecordedEvent` is the envelope. `PayloadReader`, `PayloadJson`, `PayloadDateTime`, `ActorCodec`, `AnchorCodec`, and `EventCodec` form the codec layer, with the D37 docblock. A foundation agent built the codec layer, two agents wrote the events in parallel, and a verifier wrote the round-trip and strictness tests. A review with adversarial verification confirmed 12 findings: 2 code defects and 10 test gaps. All are fixed.

- **Deviations and decisions:**
  - Event classes are named like their `EventType` case. `App\Domain\Event\ReviewClosed` shares its short name with the error `App\Domain\Error\ReviewClosed`, so a file that uses both aliases one of them.
  - Payload JSON is compact (`JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE | JSON_PRESERVE_ZERO_FRACTION | JSON_THROW_ON_ERROR`). An empty payload is `{}`. Payload keys follow the order of the architecture table.
  - Dates are `Y-m-d\TH:i:s\Z` in UTC. Encoding a fraction of a second or a year outside 0000-9999 throws. `CommitLinked` and `CommitFound` reject such a `committedAt` with `InvalidInput` and store it in UTC. A crafted git commit with a year 10000 would otherwise make a review log unreadable forever.
  - Commit subjects are repaired at construction: each invalid UTF-8 sequence and each NUL becomes U+FFFD, through the shared `App\Domain\Text\Utf8::scrub()` that `SnapshotCapture` also uses. `git fast-import` can store a Latin-1 subject, which JSON cannot encode.
  - `RecordedEvent` requires a request ID exactly for `request.*` types and the system actor for `commit.found`, as the architecture table says.
  - `CommitFound` and `BatchSubmitted` reject duplicate IDs, as `uniqueItems` of `event.schema.json` requires. `BatchSubmitted` allows empty lists, so an older release can read a later summary-only batch.
  - `PayloadReader` reads `{}` and an object keyed 0 to n as a list. Only the codec writes payloads, and it writes lists as arrays. A test pins this.
  - The `request.wont_do` reason counts code points after `mb_trim`, as JSON Schema `minLength` does.
