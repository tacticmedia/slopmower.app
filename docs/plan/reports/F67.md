## Report: F67 Full-width Changes tab

- **Status:** Done 2026-10-19.
- **Summary:**
  - `RootLayout.module.css` has two rules: `.page:has([data-full-width]) .main` sets `max-width: none`, and `.page:has([data-code-browser]) .main` sets `padding-bottom: 0`.
  - `ReviewLayout` sets both attributes on the Code tab. `RequestDetail` sets `data-full-width` on its `article` while the Changes tab shows.
  - From 1012 px, `.page[data-full-width] .layout` of `RequestDetail.module.css` is one column with the areas `'tabs' 'main'`, and the sidebar has `display: none`. Below 1012 px, the layout does not change.
  - The Conversation tab, the lists, the repository pages, and Settings stay centered at 1280 px.
- **Files:**
  - Front end, changed: `assets/layout/RootLayout.module.css`, `assets/routes/reviews/ReviewLayout.tsx`, `assets/routes/requests/RequestDetail.tsx`, `assets/routes/requests/RequestDetail.module.css`.
  - Tests, changed: `tests/ui/ChangesTab.spec.ts`.
  - Docs, changed: `docs/architecture.md` section 8 (the Request detail row), `docs/user/reviewing.md` ("The request page").
  - Created: `docs/plan/reports/F67.md`.
- **Tests added:**
  - UI `ChangesTab`: "At 1600 px the Changes tab spans the window without the sidebar, and the Conversation tab stays 1280 px wide with it". On the Conversation tab, `main` is at most 1280 px wide and the sidebar is visible. After a click on "Changes", the commit section is wider than 1280 px and the sidebar is hidden.
  - Mutation check: without `data-full-width` on the request `article`, the test fails with a commit section of 968 px.
