- **Deviations:**
  - The regression spec holds the PHP grammar chunk back until the annotation has changed, in addition to the 4x CPU throttling and the 100 ms latency. Throttling alone hit the window in 1 of 6 runs on this host. With the hold, the old code fails every run.
  - Assertions of server-side effects became assertions on the requests that the page sent. "Sign out ends the session, and /api/v1/me then answers 401" checks the `POST /logout` with its CSRF token. "MCP initialize works with the new token" checks that the dialog shows the secret that T2 returned and the MCP URL of A1. "After revoke, the same call gets 401" checks the T3 request for the token. Each title stays as the milestone requires.
  - "The tree expands directories on demand" reads the `dir` values from the mock's request log, not from the Resource Timing entries.
  - "Connect adds it to the connected repositories": R3 answers `sync.state` cloning, as docs/specs says. The spec then finishes the clone and pushes a `repository` live update before it expects "Ready". The Panther test saw "Ready" at once, because the e2e site runs the clone job through `sync://`.
  - "A second submit while T2 runs creates no second token" holds the T2 response until the second submit has run, instead of a timer.
  - The configure link of GitHubCandidates comes from the fixture `lists.candidate-list.json` (`holistic-review`), not from the `.env.test` slug (`holistic-review-test`).
  - "The copy button shows Copied" grants the clipboard permissions and also checks the copied text. Without them the button shows "Copy failed": `writeText` rejects with `NotAllowedError: Write permission denied`. The Panther Chrome granted the write.
  - RangeComment failed first, and the app has no bug. After a scroll, the code view ignores the pointer for 120 ms. Playwright pressed the "+" within that window, so the press hit the row container and no comment box opened. With a 107 ms wait, the same gesture opened "Comment on lines 5 to 9". The slower WebDriver round trips of Panther never hit the window. `dragFromPlus()` now waits until the "+" receives the pointer.

- **Risks discovered:**
  - `@pierre/diffs` 1.5.1 compares file objects by identity in `VirtualizedFile.finalizeRender()`, but by `cacheKey` everywhere else. A caller that builds a new object for the same file before the first highlight arrives leaves the view blank until the page reloads. `CodeFile.tsx` now memoizes the object. `CommitDiff.tsx` passes no annotations and memoizes its diff.
  - `config/reference.php` changes on every `cache:warmup`, in the baseline too. This commit leaves it out.
