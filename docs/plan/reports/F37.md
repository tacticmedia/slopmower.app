## Report: F37 Symbols service address

- **Status:** Done (awaiting commit).
- **Summary:** `SYMBOLS_HOST` and `SYMBOLS_PORT` set the listen address and the TCP port of the `symbols` service, by default `127.0.0.1` and `3000`. An empty value means the default. The `symbols` stage of the `Dockerfile` sets `SYMBOLS_HOST=0.0.0.0`, so the compose network reaches the container without a change to `compose.yaml`. The start line names the bound address from `server.address()`. `docs/deployment.md` describes both variables, and its firewall step applies only when the PHP processes run on another host.
- **Files:**
  - Service, changed: `symbols/src/server.ts`, `Dockerfile` (`symbols` stage).
  - Tests, created: `symbols/src/server.test.ts`.
  - Docs, changed: `docs/deployment.md` (Requirements, Run, Network access, Configure the application), `docs/plan/README.md` (environment table), `docs/plan/features.md`.
  - Created: `docs/plan/reports/F37.md`.
- **Tests added:**
  - Vitest, `ServerTest`:
    - "Without SYMBOLS_HOST, the service listens on 127.0.0.1";
    - "SYMBOLS_HOST and SYMBOLS_PORT set the listen address";
    - "An invalid SYMBOLS_PORT stops the service with exit code 1".
- **Verification:**
