## Report: S07 Collapse layers around commands

- **Status:** Done (awaiting commit).
- **Evidence check:**
  - One action passes through a domain command, the decider, an application wrapper, `RequestCommands`, a REST action, and an MCP tool: held for Q7, Q8, and Q10. `src/Application/LinkCommits.php`, `UnlinkCommit.php`, and `MarkReadyForReview.php` each called one `RequestCommands` method; `src/Controller/Api/CommitLinkController.php`, `AgentRequestController.php`, and `src/Mcp/Tool/LinkCommitsTool.php`, `UnlinkCommitTool.php`, `MarkReadyForReviewTool.php` called the wrappers.
  - The wrappers hold the git work outside the event transaction (D26): held. `LinkCommits` pins before the transaction and unpins on failure when no other link names the commit, then queues a debounced fetch for a pending link; `UnlinkCommit` unpins after the commit; `MarkReadyForReview` runs one `fetchNow()` between two attempts.
  - `RequestCommands::markReadyForReview()` took an `$availability` argument that no caller passed: dead, removed. With it, the `$availability` match in `RequestDecider::assertCommitsAvailable()` is dead too: removed, so any pending link gives `commits_not_available`. `link_commits` keeps its use.
  - Interfaces with one implementation: only `Index\SymbolExtractor` (`PhpSymbolExtractor`), held, `src/Index/`. `TenantOwned` has 16 implementors, `RequestCommand` 10, `DomainEvent` 14, `QueryInput` 9: kept, each is a real type over many classes.
  - Domain purity rule (`tests/Unit/Conventions/DomainPurityTest.php`, plan M02): it holds for all of `src/Domain`. The deciders, reducers, event codecs, and matching algorithms run in the unit suite without the kernel, and their value types (`Actor`, `Anchor`, `Error`, `Git`, `Identity`, `Location`) are in the same closure. `Domain\Repository` and `Domain\ApiToken` are outside the event model but already pure, so the rule costs no code there; a narrower scope would make the test longer and the code no smaller.
- **Summary:** `RequestCommands::linkCommits()`, `unlinkCommit()`, and `markReadyForReview()` take the domain command, do the git work outside the event transaction with the same pin-before and unpin-on-failure order, and run the command through `CommandExecutor` under the tenant row lock. `linkCommits()` returns the `LinkCommitsResult`, because only it knows whether the clone had the commit. The REST actions and MCP tools call `RequestCommands` directly, as the other request commands already did. `BlobSymbols` takes `PhpSymbolExtractor` directly. The domain purity rule stays and D44 says why. On `main` after S04, `src` has 394 files and 25169 lines (4 files and 153 lines fewer); `tests` has 268 files and 22966 lines (1 fewer).
