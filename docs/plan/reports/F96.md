## Report: F96 Send one draft now

- **Status:** Done 2026-11-03.
- **Summary:**
  - D5 takes the optional `draftIds`, 1 to 500 unique ULIDs (D101). `SubmitDraftsInput` checks them with `Count`, `Unique` in upper case, and `All` with `Ulid`, as `LinkCommitsInput` does.
  - `DraftController::submit` filters the drafts of `findOfUser` inside the draft lock and the transaction. When fewer drafts match than `draftIds` names, it throws 422 `invalid_input` on `draftIds` before it decides an event, so nothing changes. It deletes exactly the drafts that it submits.
  - The `DraftBox` menu has "Send now" while the review is open. The intent `sendDraft` sends D5 with `{draftIds: [draftId]}`, no summary, and no delivery. The draft hides at once with the optimistic state of Delete and comes back with the error when D5 fails. The action records the seq of `batch.submitted` with `eventPositions.written()`, as the "Submit feedback" action does, so the live update of the batch causes no second revalidation.
  - The fake D5 of the UI suite submits only the drafts of `draftIds` and answers 422 for an ID that is not a draft.
