- **Deviations and decisions:**
  - `details()` returns domain objects (`RequestId`, `Action`, `RequestStatus`, `?Actor`, `DateTimeImmutable`, `CommitSha`, `RepositoryId`, `RepositoryUnavailableReason`), not JSON scalars. M11 and M15 normalize them. The Actor JSON needs `name` and `avatarUrl`, which come from the users table, so the domain cannot build it.
  - `DomainError` subclasses exist for the seven codes that the milestone lists. `unauthorized`, `forbidden`, and `internal_error` come from Security and the exception listener (M10, M11).
  - `Location` has no `target` field. Architecture section 3 lists the fields without it. The `target` of location.schema.json is a representation property that the caller adds (M13, M29).
  - `RepoPath` checks the rules of the schema description segment by segment, not with the schema regex. The lookaheads of the `RepoPath` regex in `common.schema.json` use `.*`, and `.` stops at a line terminator. So the regex accepts any empty, `.`, or `..` segment after a line terminator, for example `a\n/../b` or `a\r/../b`. `RepoPath` rejects all of them. It also needs valid UTF-8, and counts the 4096 limit in characters, as JSON Schema does.
  - `RefName` follows `git check-ref-format --allow-onelevel`, refuses a leading `-`, allows 255 characters (specs README section 2.2), and needs valid UTF-8.
  - `RepositoryName::github()` accepts `[A-Za-z0-9._-]+/[A-Za-z0-9._-]+` without `.` or `..` segments, which is wider than GitHub's owner rules. Names come from the GitHub API, and logins of Enterprise Managed Users contain `_`. GitHub names compare case-insensitively, local names exactly (specs README section 7).
  - `Anchor::of()` also enforces the `AnchorInput` rules: `line` covers one line, `range` two or more, and `snapshot.lineCount` equals the line count of `range`. The stored `KindRules` alone do not.
  - `ContentSnapshot::of()` checks the counts and the hash format, but does not recompute the hash, so a stored snapshot always loads.
  - `Actor` allows an `agentName` of 1 to 64 characters, the rule of actor.schema.json, not the stricter `TokenName` pattern. A stored actor then survives a change of the token name pattern. `SymbolRef` needs a non-empty `language` and does not force `php`.
  - Whitespace for trailing whitespace and the comparison form is ASCII: space, tab, LF, VT, FF, CR. Lines split at LF only, as git counts them. `rtrim` removes the CR of CRLF. A lone CR stays inside its line.
  - Violations name default fields: `commitSha`, `blobSha`, `commit`, `path`, `ref`, `name`, `tenantId` and the other camel-case ID names, `range.startLine`, `range.endLine`, `symbol.fqn`, `snapshot.lineCount`, `userId`, `agentName`, `confidence`. String values and IDs take an optional `$field`, so a caller can name `at` or `requestIds.1`.
  - `SnapshotCapture` is a `final class` with static functions: `capture()`, `comparisonForm()`, and `normalizedHash()`, which M28 reuses.
  - The domain enums are closed sets. docs/specs marks `SymbolKind`, `Action`, and `ErrorCode` as open sets for clients. `SymbolKind::Class_` has an underscore, because `class` cannot be a case name.
  - `DomainPurityTest` is in `tests/Unit/Conventions` next to the M00 convention tests (task 5). It reads tokens and checks the namespace declaration, the top-level imports with group imports, the fully qualified names, and the unqualified calls of global functions. A namespaced core class passes, because the test asks `ReflectionClass::isInternal()`.
  - Tests beyond the acceptance list: `CommitShaPrefixTest`, `ContentSnapshotTest`, `SymbolRefTest`, and `LocationTest` give every value object an accept and a reject case ("Done"). `EnumContractTest` compares each enum with docs/specs. The other added cases each cover one rule of our own.

- **Risks discovered:**
  - A git path or ref name that is not valid UTF-8 cannot become a `RepoPath` or `RefName`. Git allows such bytes. Tree listings and symbol indexes from M11 on must skip or report those entries.
  - `Identifier::generate()` takes the ULID time from the system clock. The domain cannot import `Psr\Clock`, so a test with a frozen clock still gets real-time ULIDs. Nothing orders by ULID time: events order by `seq`.
  - The domain calls `mb_*` functions. The container has `ext-mbstring`, and `symfony/polyfill-mbstring` is installed as a dependency, but `composer.json` does not require `ext-mbstring`.
