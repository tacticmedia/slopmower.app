- **Decisions and deviations:**
  - Item 1: the error element offers the toggle, the second option of the scope file. The review layout cannot see the error of a child route through a public React Router API, and the loader data of an errored route keeps its previous value, so "focus mode does not apply" has no reliable signal. The toggle shows only while focus mode is on, as a pressed "Focus" button, the same control as in the file header.
  - Item 2: the directory state follows the open path during render: when the path changes and the directory holds the new file, it expands. A path change never collapses a directory.
  - Item 3: a summary read, not a cache. Without a filter, Q1 lists every request of the review, so the loader reads D1 and Q3 only with a filter. The review loader also reads D1, because a React Router loader cannot read the data of its parent.
  - Item 4: one scroll on mount was not enough. At mount, the commits above have no Q9 data yet, the page is not tall enough to scroll, and they grow later. `keepInView()` scrolls again on each `ResizeObserver` report of the commit list until the first wheel, touch, pointer, or key event.
  - Item 1, after review: the code layout route uses the same error element, so a V6 error at a file URL in focus mode keeps the toggle too.
  - Item 3, after review: each Q3 read has its own catch. A failed read leaves the label "Reply to a request" and keeps the list.
  - Item 5: as `DeleteReviewDialog`: Cancel is disabled and `onClose` returns early while the fetcher is busy.
  - Item 6: Ctrl+Enter and Cmd+Enter are accepted on every platform, as Cmd-click and Ctrl-click in `CodeFile`. They run the submit button of the box ("Add single comment", "Reply", "Update comment"), not the primary review button. Escape runs only where the box has Cancel, and calls `preventDefault()`, so focus mode stays. Keys during IME composition are ignored. `useFileComments` takes `select(range)` in place of `clearSelection()`, and an effect selects the range of a box that opens again with an error. `useLineSelection` loses `clear`, which had no other caller.
  - Item 7: `ThreadView` gets `symbol`, the FQN, also for a pending thread from a symbol composer. The request detail shows the FQN after the anchor link.
  - Item 8: context rows are a third `SnapshotRow` kind, `context`, numbered from `startLine - before.length` and from `startLine + lineCount`. They carry `data-context` and the muted foreground colour.
  - Item 10: a file that is not loaded yet reserves the height of its changed lines, 20 px each, the default `--diffs-line-height`, so the files below it start outside the window. A loaded file stays loaded when it collapses: the body is hidden, not unmounted. The threshold is 20 files, and Q9 still loads per commit at once.
  - Item 11: the unavailable button is a plain Primer `Button` with `aria-disabled` and a `Tooltip` of type `description`. A `disabled` button gets no pointer or focus events, so it could not show a tooltip. While V9 loads, the button stays `disabled` without a reason. The symbols loader adds `path` to its error result, so a failure of another file is not shown.
  - Item 13: a guard on `'idle' !== fetcher.state`, as `FinishReviewOverlay` had, lets a quick double click through: the double-click test failed with it, 2 calls of 1, in 10 of 10 runs. React Router commits the fetcher state in `startTransition`, and `fetcher.Form` takes no `flushSync`. `useSubmitOnce()` holds a ref, prevents the default submit, and calls `fetcher.submit(form)` until its promise settles, as `CreateTokenDialog` already does. It covers Close review, Delete review, Finish your review, Start review, Connect, Refresh, and Sign out. The `fetcher.submit()` writes in `assets/` already check a ref or the fetcher state in their handlers.
  - The check that each new test fails on the code before F07 was not run: checking out the old `assets/` in the worktree was refused. Each test asserts an element, a call, or a URL that the old code does not produce, except item 12, which covers behaviour that already worked.
