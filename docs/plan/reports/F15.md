- **Summary:**
  - `PlanToApproveLabel` shows "Plan to approve" in the request list, in the header of a thread in the code view, and next to the path in the file header when a thread of the file has a pending proposal. `ThreadView.proposalPending` comes from the Q3 `proposal` that the file loader already reads.   - The state label of a proposal entry, first match: the state of the current proposal; the first `request.proposal_approved` or `request.proposal_rejected` entry after it, before the next `request.proposed` entry; "Superseded" when a later proposal exists; else "Withdrawn". An older approved or rejected proposal keeps its decision.
  - `RequestState::proposalGateOpen()` holds the gate rule for `AllowedActions` and `RequestDecider`. When the closed gate refuses the holder's `link_commits`, `mark_ready_for_review`, or `link_pull_request`, the `invalid_transition` message ends with the reason, for example "The request is in_progress, so link_commits is not allowed: the proposal waits for the user's decision." `details` is unchanged.

- **Decisions and deviations:**
  - The unit test is one data-provider test with four cases: the three reasons and the status refusal. Each reason case uses another gated action, so all three actions are covered.
  - The reason text is built in `RequestDecider::closedGateReason()`, a private method, so the English text stays out of `RequestState`. Its `Approved` arm throws `LogicException`, because an approved proposal opens the gate.
  - `PlanToApproveLabel` takes `pending: boolean` and renders nothing when false, like `OutdatedLabel`.
  - `FileHeader` takes `planToApprove: boolean`, not a label slot. `FileRoute` computes it from the loader threads, not the optimistic list: a thread that the server has not confirmed has no proposal.
  - The UI spec approves on the request detail through "Open the proposal", then opens the file again.
  - The developer guide counts are set to the current numbers. This also corrects counts that F14 left stale: Unit 62 to 64, Functional 158 to 159, UI 40 to 42, `assets/comments/` 11 to 12.
