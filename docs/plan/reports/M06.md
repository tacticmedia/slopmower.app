# Report: M06 Review data schema

- **Status:** Done, on `main`, 2026-09-29.
- **Summary:** Entities `Repository`, `Review`, `ChangeRequest`, `Comment`, `CommitLink`, and the read-only `ReviewEvent`, with one migration. DBAL types for `CommitSha`, `BlobSha`, `RepoPath`, and `Anchor` (`jsonb` through `AnchorCodec`). `ActorEmbeddable` and `NullableActorEmbeddable`. `RequestStateMapper` maps between `ChangeRequest` and `RequestState`. A scoped review found three minor defects. All are fixed, and ten redundant tests are cut.
- **Verification:** `make check` exit 0: 1041 unit and functional tests, 2 E2E tests, PHPStan 0 errors, schema in sync.
- **Decisions:**
  - Two actor embeddables: the nullable one for `claimedBy` and `closedBy`. A null kind maps to a null `Actor`.
  - `ReviewEvent.payload` uses the DBAL `jsonb_object` type, so an empty payload stays `{}`. `RecordedEvent::requestIds()` (new in the domain) fills the `request_ids` column, as `Event.requestIds` of `event.schema.json` defines it.
  - `CommitLink` has a surrogate ULID key and a `linkedSeq` column, which orders links, because `linkedAt` keeps whole seconds and can tie. `CommitLink::relink()` reuses the row after an unlink, because Doctrine runs inserts before deletes.
  - A child entity takes its tenant from its parent (review from repository, request from review, and so on).
  - Entities refuse a time with a fraction of a second (`WholeSeconds`). They do not truncate it.
  - `Repository` keeps `defaultBranch` as a `RefName` and refuses a local directory name over 255 characters.
  - `EventLogGuard` makes an ORM flush that deletes a `ReviewEvent` throw. The tenant purge of M31 uses raw SQL.
- **Follow-ups:** in the "Carried over" section of M07 and M13.
- **Risks:** the tenant match between a child and its parent is enforced in the constructors only. There is no composite foreign key, so raw SQL could still link rows of two tenants.
