## Report: M06 Review data schema

- **Status:** Done, committed as 158c158 on 2026-10-02.
- **Summary:** `Repository`, `Review`, `ChangeRequest`, `Comment`, `CommitLink`, and the read-only `ReviewEvent` are Doctrine entities with one migration. Every one implements `TenantOwned`. IDs are `ulid` columns with typed-ID getters. `CommitShaType`, `BlobShaType`, `RepoPathType`, and `AnchorType` (`jsonb` through `AnchorCodec`) are the only custom DBAL types. `ActorEmbeddable` maps every `Actor`. `RequestStateMapper` maps `ChangeRequest` and its `CommitLink` rows to `RequestState`, and `RequestState` to `ChangeRequest`, with `awaiting` from `AwaitingPolicy`. `RecordedEvent::requestIds()` gives the `request_ids` column of `review_event`.

- **Deviations and decisions:**
  - `ReviewEvent` has no constructor and no ORM write path. M07's `EventStoreSql` inserts the rows with `PayloadJson::encode()`, so an empty payload stays `{}`. A `Types::JSONB` array property would write `[]`. Tests insert events with SQL through `ReviewDataFixtures::insertEvent()`.
  - `RecordedEvent::requestIds()` holds the rule of the `request_ids` column: payload `requestIds` for `commit.linked`, `commit.found`, and `batch.submitted`, `[requestId]` for `commit.unlinked` and request events, `[]` for review events. M07 writes the column from it.
  - `jsonb` columns use the DBAL 4.5 type `Types::JSONB`. The `jsonb` column option is deprecated in DBAL 4.5.
  - `occurred_at` is `TIMESTAMP(0) WITH TIME ZONE`, because architecture section 3 names `timestamptz`. All other times are `TIMESTAMP(0) WITHOUT TIME ZONE`, as in M05. PHP and PostgreSQL run in UTC.
  - `CommitLink` has the primary key `(request_id, commit_sha)` and no ID, as architecture section 3 lists none. The key is the "unique per request and commit" guard. Doctrine also creates an index on `request_id`, which the key already covers.
  - The columns of `ActorEmbeddable` are nullable for every embedding, because Doctrine sets column options per embeddable class. The getters of `author`, `startedBy`, and `linkedBy` throw `\UnexpectedValueException` for a null actor. Stored columns that break the `Actor` rules also throw `\UnexpectedValueException`, and the custom types turn domain errors into DBAL `ValueNotConvertible`. So corrupt rows answer internal_error, not invalid_input.
  - The types register through DoctrineBundle's `#[AsDbalType]` attribute, without YAML. `doctrine.yaml` got the mapping `Embeddable`, because the mapping driver chain resolves only `App\Entity`.
  - `RequestStateMapper` is a `final` class with static functions, like the M04 reducers: `toState(ChangeRequest, list<CommitLink>)`, `toEntity(Review, RequestState)`, `update(ChangeRequest, RequestState)`. It does not write `CommitLink` rows, because the state lacks their git data. The M07 projector writes them from the `commit.*` events. `toState()` sorts the links by `linkedAt`, then by SHA, because times have second precision.
  - `ChangeRequest` does not know `RequestState`. Its constructor takes the `request.opened` fields, and `project()` takes the others. The orchestrator columns `wontDoBy`, `lastUserCommentSeq`, `lastAgentEventSeq`, and `lastAgentEventIsQuestion` exist.
  - `Review` takes the `seq` of `review.started` as `lastEventSeq` and has `close()` and `setLastEventSeq()`. `Repository` has `local()` and `gitHub()`, which start with `syncState` `cloning` and `access` `active`. Neither has mutators for the index fields (M26) or the sync fields (M09).
  - Child entities take the tenant from their parent: `Review` from its `Repository`, `ChangeRequest` from its `Review`, `Comment` and `CommitLink` from their `ChangeRequest`. Only the `Repository` factories take a `TenantId`, so a child cannot get another tenant than its parent.
  - `Review::getRef()` and `Repository::getName()` throw `\UnexpectedValueException` for a stored value that breaks the value-object rules, as `ActorEmbeddable::toActor()` does.
  - `review_event.type` uses `enumType: EventType`, by the milestone rule. `EventType::fromString()` stays for raw SQL readers.
  - Column lengths: `title` 200 and `ref` 255 from review.schema.json, agent name 64 from `Actor`, SHA 64, `RepoPath` and long texts `TEXT`.
  - `BlobShaType` and `RepoPathType` exist as the milestone lists them. No M06 column uses them yet.

- **Risks discovered:**
  - The unique index `(tenant_id, source, name)` compares GitHub names case-sensitively, while `RepositoryName::equals()` ignores case for GitHub. The partial unique index on `github_repository_id` is the real guard for GitHub repositories.
  - `CommitLink` has a composite key with an association. `find()` takes `['request' => <ID or entity>, 'commitSha' => CommitSha]`.
