- **Decisions and deviations:**
  - `Entity\Symbol` needs no change: `kind` is `VARCHAR(255)`, and the row guard uses `SymbolRef::MAX_FQN_CHARACTERS`, the length of its three text columns.
  - The language row holds more than the grammar and the query: the separator, the wrapper node types (`export_statement`, `ambient_declaration`, and for a top-level namespace `expression_statement`), the attribute node types (TypeScript method decorators are siblings of the method), the opaque node types whose descendants are no symbols, and the doc comment pattern. These are rules that a query cannot express.
  - One symbol per `@name` node, and the first pattern of the query file wins. So `const f = () =>` is a function and not also a constant.
  - A class expression is opaque, as an anonymous PHP class: its members are no symbols. A member kind without a container is skipped.
  - A blank line may separate a `/** */` comment from its declaration, as php-parser and TypeScript allow. A run of matching comments on adjacent lines also counts, for the `//` blocks of F29.
  - Overload joining applies to functions and methods without a body field before a declaration with the same FQN and parent. Interface method overloads join too. Consecutive signatures without an implementation, as in a `.d.ts` file, also join into one symbol, so it stays anchorable. `declarationStartLine` and `docStartLine` come from the first signature.
  - `declare module 'm'` is module `m`, and `namespace A.B` is one module `A.B`. A TypeScript method signature in a class body, an abstract method, a getter, a setter, and `constructor` are methods.
  - `TreeSitterSymbolExtractor` skips a row whose kind `SymbolKind` does not know, so a `symbols` image that is newer than the PHP build drops that row instead of failing every file of the service.
  - The row guard also refuses an empty name and a line range that is not `1 <= start <= end`, so a broken service row is left out instead of a `LineRange` error, which would answer 422.
  - `CLASS_LIKE_KINDS` lives in `assets/code/symbolMatch.ts`, because `symbolItems.ts` imports `symbolMatch.ts`. `SCOPE_KINDS` is `CLASS_LIKE_KINDS` plus `function` and `method`.
  - V14 in `rest-api.md` now says "among the PHP symbols", which D56 decides. The scope named only V9 and V16.
  - The service-down case of Q3 is in `SymbolAnchorTest`, a `WebTestCase`, so it checks the HTTP 500. It asserts no cache row for the target commit, because opening the request caches the location at the review commit.
  - The worker needs `make worker-restart` after this change: a worker started before it inserts `indexed_blob` rows without `language`.
- **Follow-ups and new ideas:**
  - The Symbols menu heads the top-level group "Functions and constants", and it now also holds top-level TypeScript types. "Top level" fits all languages.
  - A getter and a setter of one property share an FQN, so the menu marks both as not unique and neither becomes a symbol anchor.
  - TypeScript parameter properties (`constructor(private x)`) are no properties, while PHP promoted parameters are.
  - A top-level `const` inside a block, for example in an `if`, is a constant symbol.
  - The per-file HTTP round trip dominates small files. The candidate "Concurrent symbol requests in the index job" covers it.
