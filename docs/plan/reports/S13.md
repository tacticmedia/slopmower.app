## Report: S13 Namespace cycles

- **Status:** Done (awaiting commit).
- **Measure:** a PHP script under `var/` (git-ignored, not committed) reads every file of `src/` with `PhpToken`. Nodes: `App\<Top>`, and `App\Domain\<Second>` inside `src/Domain`. Edges: top-level `use` imports, fully qualified names, and qualified names in code. A `use` that serves only a `{@see}` or `{@link}` link is not an edge. A `use` that serves a docblock type, for example `@param list<CommitSha>`, is an edge. Tarjan's algorithm gives the strongly connected sets. A pair is two namespaces that import each other.
