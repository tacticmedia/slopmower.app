- **Deviations and decisions:**
  - JSON access goes through three DQL functions registered in `doctrine.yaml` (the M06 follow-up): `JSONB_CONTAINS` (`@>`) for the thread, `JSONB_PATH_TEXT` (`#>>`) and `JSONB_PATH_INTEGER` for the Q1 path filter and sort. No column and no migration.
  - The thread holds every event whose `request_ids` contains the request, except `batch.submitted`. That includes `commit.unlinked`, which thread-entry.schema.json lists and M04's `lastEventSeq` rule follows. It is the same fold as the projector, so `statusAfter` comes from `RequestReducer`.
  - `Event.requestId` of `commit.unlinked` is its payload `requestId` (event.schema.json), through `RecordedEvent::subjectRequestId()`. `Event.statusAfter` is null for `commit.linked` and `commit.found`; a thread entry of them carries the status of the thread's request.
  - A command result takes `statusAfter` from the thread up to the command's last event, not from the projection read afterwards, so a concurrent command cannot change it. One extra query per command.
  - V10 runs in `ReadSnapshotSql`: `SET TRANSACTION ISOLATION LEVEL REPEATABLE READ, READ ONLY`, then `event_seq` of the tenant row. The reads inside refresh managed entities. `EventLogQuery` stays public and unused by M13; `UpdatesQuery` reads through `ReviewEventRepository::findInRange()` with the upper bound, the actor filter, and the limit (the M07 follow-up).
  - V10 is S and B, so the agent rule is in: `awaiting = agent`, without the `in_progress` requests that another agent holds. One bearer test covers it.
  - `AnchorFactory` checks the kind, the path syntax, and the range rules (`Anchor::rangeViolations()`) before it reads the clone, so 422 comes before 409 `repository_unavailable`. A closed review whose clone is not ready gives `review_closed`, as the check order says. An unknown path and a file that is not renderable give 422 on `anchor.path`. The renderable rule is `FileContent`'s (`text()`).
  - `kind: symbol` gives 422 on `anchor.kind` ("Symbol anchors are not available."). M27 adds symbol anchors. `AnchorInput.symbol` is mapped (`SymbolInput`), and a `symbol` on a `line`, `range`, or `file` anchor gives 422 on `anchor.symbol`, because kind and fields do not agree (orchestrator review).
  - A `line` or `range` anchor on a text file that is not valid UTF-8 gives 422 on `anchor.path`, as a file that is not renderable does, because JSON cannot carry its snapshot (orchestrator decision).
  - Q1 lists: `status` and `awaiting` are comma-separated; an unknown value gives 422 on the field. An unknown `sort` gives 400, because the serializer refuses the enum, as M11 decided for `source`. `outdated` matches nothing, because every request has `outdated` null until M29.
  - Q1 sort keys: `created` `[id]`, `updated` `[unix second, id]` with `id` ascending after `updatedAt` descending, `path` (`anchor.path`, start line or 0 for a file anchor, `id`). A path cursor holds only the last request ID, and the next page reads that request's path and start line, because a path can be longer than the 2,048-character cursor (orchestrator decision). A missing request or an `updated` time outside the years 1 to 9999 gives 422 `invalid_input`. The path order is the database collation; the keyset uses the same one. The filter hash holds the sorted list values, `path`, `outdated`, and `sort`.
  - Text input: `NotBlank(normalizer: 'trim')` and `Length(max: 65536)` on `body` and the required `note`; `WontDoInput` has `Length(min: 20, normalizer: 'trim')`, which gives the message of `error.invalid-input.json`.
  - `RequestPage`, `RequestCommandResult`, `UpdatesPage`, and `UpdatedRequest` have no normalizer: the framework `ObjectNormalizer` emits their public properties, as for M11's `RepositoryPage`. So no `RequestCommandResultNormalizer` exists.
  - `public` is dropped on `RequestCommands`, which the controllers consume. No M13 route is bearer-only, so the bearer-only message waits for M16.
  - Tests run agent commands through `RequestCommands` with an agent actor (`asAgent()`), because Q5 and Q7 are M16 routes.
